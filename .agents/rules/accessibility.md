# Accessibility Rules

- HTML semântico.
- Um único H1 principal.
- Hierarquia de headings sem saltos arbitrários.
- Todos os controles devem funcionar via teclado.
- Focus state sempre visível.
- Contraste adequado entre texto e fundo.
- Imagens informativas com alt descritivo.
- Imagens puramente decorativas com alt vazio.
- Não transmitir informação apenas por cor.
- Áreas de toque confortáveis no mobile.
- FAQ deve possuir interação acessível.
- Menu mobile deve ter nome acessível, foco e fechamento previsível.
- Respeitar `prefers-reduced-motion`.
- Não colocar texto essencial dentro de imagens.
