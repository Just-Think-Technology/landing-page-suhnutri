# Visual QA Checklist

- [ ] Hero comunica o posicionamento imediatamente
- [ ] H1 não quebra de forma estranha
- [ ] CTA primário se destaca
- [ ] Header não ocupa espaço excessivo
- [ ] Fotos têm crop profissional
- [ ] Verde não domina a página
- [ ] Cards não estão excessivamente repetitivos
- [ ] Seções têm ritmo visual
- [ ] Serviços são escaneáveis
- [ ] Segmentos são reconhecíveis
- [ ] Processo é fácil de entender
- [ ] CTA final possui contexto suficiente
- [ ] Footer está organizado
- [ ] Não existe overflow horizontal
- [ ] Animações não distraem
