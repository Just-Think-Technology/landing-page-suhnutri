# Skill — Frontend

Carregar para implementação ou refatoração de UI.

## Processo

1. Ler contexto de marca.
2. Ler arquitetura da página.
3. Definir semântica HTML.
4. Criar estrutura responsiva.
5. Aplicar tokens Tailwind.
6. Adicionar shadcn somente onde necessário.
7. Criar interações locais.
8. Adicionar animação depois que o layout estiver correto.
9. Validar mobile.
10. Executar checklist visual e de acessibilidade.

## Definition of done

- sem componentes gigantes
- sem estilos duplicados
- sem Client Component desnecessário
- conteúdo acessível sem JavaScript
- responsivo
- pronto para SEO
