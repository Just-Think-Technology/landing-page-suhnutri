# Skill — Visual QA

Avaliar a página em pelo menos:

- desktop amplo
- desktop padrão
- tablet
- mobile pequeno
- mobile padrão

## Procurar

- overflow horizontal
- textos cortados
- quebras ruins de heading
- CTA fora da viewport
- imagens distorcidas
- contraste insuficiente
- espaçamento inconsistente
- animação piscando
- elementos aparecendo tarde demais
- navegação mobile problemática

Comparar com a direção visual do `.agents/context/brand.md`, não com templates genéricos.
