# Skill — Animation

Carregar ao implementar ou revisar animações.

## Objetivo

Criar movimento refinado com anime.js sem transformar a landing page em uma demonstração de efeitos.

## Processo

1. Identificar o objetivo narrativo da animação.
2. Definir o estado inicial e final.
3. Preferir opacity/transform.
4. Implementar a menor animação possível.
5. Garantir reversibilidade quando houver scroll.
6. Testar mobile.
7. Testar reduced motion.
8. Verificar performance.

## Definition of done

- animação não impede leitura
- não causa layout shift relevante
- não cria dependência de mouse
- funciona ao subir e descer a página
- não quebra em touch
- reduced motion continua funcional
