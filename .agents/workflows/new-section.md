# Workflow — New Section

1. Definir objetivo da seção.
2. Identificar informação aprovada.
3. Escolher hierarquia semântica.
4. Definir desktop/mobile.
5. Implementar layout.
6. Implementar estados.
7. Validar acessibilidade.
8. Adicionar animação somente se agregar.
9. Rodar visual QA.
10. Revisar conversão.

Uma seção não está pronta apenas porque "parece bonita".
