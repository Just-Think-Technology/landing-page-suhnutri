# Quality Rules

Antes de considerar uma seção pronta:

### Conteúdo
- O texto está aprovado?
- Há alguma promessa não comprovada?
- A linguagem está clara para donos e gestores de estabelecimentos?

### UX
- O visitante entende a seção em poucos segundos?
- Existe uma ação clara quando apropriado?
- A hierarquia visual está correta?

### UI
- O design segue os tokens?
- Há excesso de cards, ícones ou efeitos?
- O mobile foi tratado como composição própria?

### Técnica
- Server/Client boundary está correta?
- Há JavaScript desnecessário?
- A animação pode ser simplificada?

### Acessibilidade
- Semântica correta?
- Keyboard navigation?
- Focus?
- Contraste?
- Reduced motion?

### SEO
- Heading hierarchy?
- alt?
- metadata?
- conteúdo rastreável?
