# Suh Nutri Agent System

Sistema de contexto e regras para agentes de desenvolvimento.

```text
.agents/
├── AGENTS.md
├── README.md
├── context/
├── rules/
├── skills/
├── workflows/
└── checklists/
```

A pasta é organizada por **progressive disclosure**: primeiro as regras globais, depois o contexto necessário para cada tarefa.

## Regra de ouro

A landing page deve transmitir:

**segurança → competência → clareza → proximidade → ação**

Evitar uma estética hospitalar, excessivamente acadêmica ou de "site de nutricionista clínica". O posicionamento é consultoria técnica para negócios de alimentação.
