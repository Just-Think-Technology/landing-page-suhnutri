# Workflow — Visual Change

1. Identificar o problema visual.
2. Verificar se é token, layout, conteúdo ou componente.
3. Corrigir na camada apropriada.
4. Verificar desktop e mobile.
5. Verificar contraste e acessibilidade.
6. Verificar se a mudança afeta outras seções.
7. Revisar animações relacionadas.
